InferenceOS Console Font

The InferenceOS console glyph atlas is derived from JetBrains Mono Regular:
https://github.com/JetBrains/JetBrainsMono

Font License, Version 1.1. The complete license is in OFL.txt beside this file.

tools/image/import_alpha4_font.ps1 rasterizes ASCII glyphs into 12x24 cells and
stores their 4-bit coverage values in inferenceos-console-alpha4.rle.b64. The
normal build expands that checked-in source deterministically; it does not need
the TrueType source or an installed host font.
